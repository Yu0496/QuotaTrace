## 结论与用户选定口径

软件统计的是**订阅消耗参考价值**。保留固定非促销基准，金额不代表 API 账单、实际订阅扣费或剩余美元余额。此前以 Sol 当前 API 促销价不同为由判定订阅参考基准错误，口径不成立，已撤回。Sol 的输入/缓存读取/缓存创建/输出基准保留为每百万 Token **$5 / $0.5 / $6.25 / $30**。

Token 参考金额可以按明确规则计算；额度百分比没有已验证的固定美元兑换关系。满额参考金额改为同周期本机样本外推，并显示无法估算的原因。

## 金额与额度之间的关系

1. 参考金额 =（未命中输入 × 输入基准 + 缓存读取 × 读取基准 + 缓存创建 × 创建基准 + 输出 × 输出基准）/ 1,000,000。读取/创建缓存不再重复包含于未命中输入，输出已包含思考用量。
2. 按单次请求判定长上下文，保留服务档位。Astra、GPT-5.6、GPT-5.5 Fast 的订阅倍率为 2.5，GPT-5.4 为 2；不能套用 API Priority 的价格系数。依据：[官方 Fast 说明](https://learn.chatgpt.com/docs/agent-configuration/speed)。
3. 满额参考金额 = 两次采样间本机参考金额 / 两次快照剩余比例之差。样例：剩余 80% 降为 70%，区间本机参考金额 $2，外推满额为 $20；不能假定本机已经记录了从 100% 开始的全部消耗。
4. 使用同模型池、同周期、同套餐的快照；末次快照须在 15 分钟内，观察下降至少 5 个百分点。额度回升、周期/套餐变化或采样间隔超过 36 小时重新建立基线。缺失本机用量或存在未定价部分时不输出满额金额。
5. 其他设备、云端任务、日志缺失及模型组合变化仍会影响外推。本机样本不能证明官方额度与美元严格成比例。[官方额度与 Token rates](https://learn.chatgpt.com/docs/pricing)
